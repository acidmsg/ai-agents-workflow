# Отчёт: Разворачивание Phase 0 мультиагентной системы

**Дата выполнения:** 2026-07-18

**Скрипт:** [`scripts/bootstrap-phase0.sh`](scripts/bootstrap-phase0.sh) (540 строк, версия 1.0.0)

---

## Общее описание задачи

Создан идемпотентный bash-скрипт для разворачивания **Phase 0** базовой инфраструктуры мультиагентной системы на VPS под управлением Ubuntu/Debian. Скрипт выполняет полную настройку среды: создание пользователей и групп, установку линтеров, развёртывание секретов и конфигурации, установку оркестратора n8n, настройку sudo-правил и финальную верификацию.

Система включает четырёх агентов:

| Пользователь       | Роль               |
| ------------------ | ------------------ |
| `n8n_user`         | Оркестратор n8n    |
| `openclaw_user`    | Кодер OpenClaw     |
| `antigravity_user` | Критик Antigravity |
| `hermes_user`      | Утилита Hermes     |

Все агенты объединены в общую группу `ai-workers` с общим доступом через SGID-бит.

## Ключевые свойства скрипта

| Свойство                  | Описание                                                                                                                                       |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **Идемпотентность**       | Каждый шаг проверяет наличие ресурса перед созданием. Повторный запуск не создаёт дубликатов — выводит `[SKIP]` для уже существующих объектов. |
| **Цветной вывод**         | `[OK]` — зелёный, `[SKIP]` — жёлтый, `[FAIL]` — красный, `[STEP N]` — жирный.                                                                  |
| **Обработка ошибок**      | `set -euo pipefail`; явный подсчёт ошибок в `FAIL_COUNT`; итоговый exit-код равен числу ошибок.                                                |
| **Проверка зависимостей** | Предварительная верификация Node.js, Python 3, дискового пространства до начала изменений.                                                     |
| **SGID-доступ**           | Группа `ai-workers` + SGID-бит (2775) на всех общих директориях — любой агент может создавать файлы, доступные остальным членам группы.        |

## Действия после выполнения

После успешного завершения Phase 0 (`FAIL_COUNT = 0`) необходимо выполнить следующие шаги:

1. **Замена плейсхолдеров в секретах:**
   - `/opt/secrets/shared.env` — `DEEPSEEK_API_KEY`, `GITHUB_TOKEN`
   - `/opt/secrets/n8n.env` — `LINEAR_API_KEY`
   - `/opt/secrets/antigravity.env` — `ANTI_GRAVITY_TOKEN`

2. **Заполнение `repo-map.json`:**
   - Добавить репозитории агентов в массив `repos` в файле `/opt/config/repo-map.json`

3. **Установка CLI-инструментов агентов:**
   - `openclaw_user` — установка OpenClaw CLI
   - `antigravity_user` — установка Antigravity CLI
   - `hermes_user` — установка Hermes CLI

4. **Создание `agent_loop.sh`:**
   - Разместить скрипт цикла агента в `/opt/scripts/agent_loop.sh` с правами на выполнение от `openclaw_user`

5. **Настройка n8n:**
   - Открыть веб-интерфейс `http://<VPS>:5678`
   - Настроить workflow, используя секреты из `/opt/secrets/`
   - Перезапустить n8n: `systemctl restart n8n`
